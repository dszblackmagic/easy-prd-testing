# 执行记录

说明：本文件用于单个优先级目录。只记录本优先级用例，不写跨优先级汇总。

## 状态与证据说明

- `通过`：已执行，实际结果与预期一致。
- `失败`：已执行，实际结果与预期存在已确认的偏差。
- `阻塞`：因账号、权限、测试数据、环境或依赖条件无法继续执行；默认不直接转为缺陷。
- `未测`：本轮未执行或被排期跳过。
- `待确认`：执行结果涉及需求、原型、字段来源或业务规则疑问，尚不能判定通过或失败。

每条已执行用例必须填写“实际结果摘要”，它是结果结论，不等同于诊断证据。截图、Console、Network、视频、Trace 和 HAR 只有在执行工具实际产生时才填写摘要或相对路径；未产生时填写 `未产生（原因）`，不得根据预期能力推测或补写。通过用例默认只保留结果摘要；失败、字段差异和高风险提示场景按可用能力补充证据，证据缺失时记录原因。
