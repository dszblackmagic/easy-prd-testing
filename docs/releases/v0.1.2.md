# Easy PRD Testing v0.1.2

## 更新亮点

- 新增 `self-update` Skill，可通过自然语言检查并升级整套 Easy PRD Testing。
- 新增带 SHA-256 校验、安装形态识别和事务切换的零依赖升级引擎。
- 新增标准 Release Asset、版本化升级清单和三平台发布门禁。
- 升级前展示版本与更新摘要，只有用户明确确认后才修改安装文件。

## 更新内容

### 整套 Skills 自更新

- 支持受管副本与官方 Git 克隆两种安装形态。
- 受管副本在临时目录完成下载、解包和验证后再切换安装目录。
- Git 安装只允许干净工作区，并固定到已发布的正式 Tag。
- 符号链接、不完整副本、未知升级协议和需要人工迁移的版本默认拒绝自动升级。

### 完整性与失败保护

- 使用 GitHub Release Asset 提供的 SHA-256 digest 校验下载内容。
- Release 包携带完整受管文件哈希清单，用于发现缺失、修改和未知文件。
- 升级失败时保留或恢复原安装；升级成功后不保存历史备份。
- 安全解包器拒绝路径穿越、符号链接、硬链接、设备文件和超限归档。

### 发布流程

- 推送 `v*` Tag 后由 GitHub Actions 执行 Linux、macOS 和 Windows 测试。
- 发布工作流在所有验证通过后构建标准压缩包和 `latest.json`。
- 本文件是 `v0.1.2` GitHub Release Notes 的唯一来源。

## 升级说明

`v0.1.2` 是首个原生支持自然语言自更新的版本。`v0.1.1` 及更早安装需要先按照 README 中的迁移提示重新安装一次；完成迁移后，用户只需表达“升级版本”“更新 Skills”或相近含义，AI 即可进入安全升级流程。

升级成功后，请新建 AI 会话或重新加载当前工具的 Skills / Plugin，使新版本规则完整生效。
